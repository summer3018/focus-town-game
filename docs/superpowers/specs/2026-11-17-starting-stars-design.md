# 開始時スター（30★）の設計

## 目的
最初に開いたとき星が0で、集中を1回終えるまで何も建てられないのを避ける。最初の1分で「建てる楽しさ」に触れてもらう。

## 方針（検討した案）
- **A. 開始時に星を配る（採用）**：変更が最小。何を建てるか自分で選べる。
- B. 最初の1軒だけ無料：判定と表示の追加が必要で変更が増える。
- C. 最初から建物を置く：自分で建てる体験が最初の集中のあとになる。

## 決めたこと
- `src/core/config.ts` に `STARTING_STARS = 30` を追加。
- `createNewSave()` の `stars` 初期値に使う。新規プレイヤーのみ対象。既存セーブは変更しない（二重付与なし）。
- `totalEarnedStars`（記録画面「ためた合計」）には含めない。
- 説明の3枚目に「はじめに30★をプレゼント。さっそく1軒建ててみましょう。」を追記。
- テスト：新規セーブが30★で始まることを追加。0★前提の既存テストは数値を合わせる。
- README のバランス表に開始時30★を追記。

## やらないこと
- 集中の報酬量・建物の価格は変えない。
